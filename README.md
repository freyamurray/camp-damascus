# Camp Damascus
Welcome to my little art project, inspired by the book *Camp Damascus* by Chuck Tingle. This is the imagined website for the fictional Christian gay conversion camp Camp Damascus. It features standard website features based on my research into other Christian summer camps, as well as a jumpscare page based on the events of the book. 

### CWs
This site contains jumpscares, eyestrain, flashing images, and autoplay. These all require javascript to be enabled in your browser.
